PLATE CLUB 3.0 — ПОЛНЫЙ ПРОЕКТ
================================

ЧТО ВНУТРИ
- index.html — новый интерфейс игры.
- server.py — API и игровая база SQLite.
- requirements.txt — библиотеки Python.
- START_GAME.bat — установка зависимостей и запуск на Windows.
- README.txt — эта инструкция.

ЧТО РЕАЛИЗОВАНО
- Регистрация и вход по логину/паролю.
- Серверное сохранение баланса, XP, номеров и статистики.
- Генерация номеров четырёх уровней редкости.
- Гараж, продажа номеров и защита номеров в музее.
- Альбом регионов с наградой за пять номеров одного региона.
- Общий рынок игроков: выставление лотов, покупка и снятие своих лотов.
- Серверный рейтинг игроков.
- Ежедневный бонус и серия входов.
- Кейсы за виртуальные монеты.
- Достижения.
- Сезонный пропуск с серверными наградами.
- Выбор рамки профиля за виртуальные монеты.
- Экспорт коллекции в JSON.

КАК ЗАПУСТИТЬ НА WINDOWS
1. Установи Python 3.10 или новее с python.org. При установке отметь "Add Python to PATH".
2. Распакуй архив в отдельную папку.
3. Дважды нажми START_GAME.bat.
4. Дождись установки библиотек и открытия браузера. Если браузер не открылся, зайди на http://127.0.0.1:8000.
5. Создай аккаунт внутри игры. Для тестирования рынка создай второй аккаунт в другом браузере или приватном окне.

ВАЖНО
- Пока сервер работает только на твоём компьютере, рынок доступен только этому локальному экземпляру.
- Чтобы играть с другими людьми через интернет/Telegram, нужно разместить сервер на хостинге с HTTPS и настроить домен/публичный доступ. Не выставляй локальный сервер в интернет без дополнительной настройки безопасности.
- SQLite база plate_club.db создаётся автоматически рядом с server.py.
- Не используй реальный пароль от почты или других важных аккаунтов.
- В игре только виртуальная валюта; реальных платежей нет.

ПРОВЕРКИ
Python-синтаксис server.py и JavaScript index.html проверены. Полный end-to-end запуск с установкой библиотек в этой среде не выполнялся.
